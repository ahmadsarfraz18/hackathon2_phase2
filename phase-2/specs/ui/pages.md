# UI Specification: Pages

**Feature Branch**: `004-ui-system`
**Created**: 2026-01-08

## Routes & Pages

### 1. root (/)
- **Target**: Marketing landing or redirect.
- **Goal**: Introduce the app, call to action (login/signup).

### 2. /auth/login
- **Target**: Login page.
- **Goal**: Authenticate existing users.

### 3. /auth/signup
- **Target**: Registration page.
- **Goal**: Onboard new users.

### 4. /dashboard (Protected)
- **Target**: Main application interface.
- **Goal**: View and manage tasks. Include:
  - Task creation form.
  - Filterable list of tasks.
  - Search bar.

### 5. /profile (Protected)
- **Target**: User settings.
- **Goal**: Manage account details, change theme, logout.
