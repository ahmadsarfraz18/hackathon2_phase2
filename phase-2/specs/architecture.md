# System Architecture - Hackathon Phase-2

## Overview
This document defines the architecture for Phase-2 of the Hackathon Todo App: a full-stack web application with user isolation and secure authentication.

## Purpose
Transitioning from a Phase-I CLI application to a modern web architecture while maintaining Spec-Driven Development (SDD) principles.

## Core Stack
- **Frontend**: Next.js 16+ (App Router, Server Components)
- **Backend**: FastAPI (Python 3.13+, Async)
- **Database**: Neon (Serverless PostgreSQL)
- **Auth**: Better Auth + JWT
- **ORM**: SQLModel (Pydantic + SQLAlchemy)

## Request Flow
1. **Browser**: Client interacts with Next.js frontend.
2. **Frontend (Server/Client)**: Next.js makes requests to FastAPI.
   - Client-side: `fetch()` with JWT in Header.
   - Server-side: Server Actions/Components with JWT propagation.
3. **Backend (FastAPI)**:
   - Receives request.
   - JWT Middleware validates token.
   - Endpoint filters operations by `user_id`.
4. **Database (Neon)**: SQLModel executes scoped queries.

## Authentication & Security
### Better Auth (Frontend)
- Manages sessions and OAuth/Credential login.
- Generates JWT for backend consumption.
- Stores session in secure, httpOnly cookies.

### JWT Security (Backend)
- Stateless validation using the shared secret/public key from Better Auth.
- Middleware extracts `user_id` from the payload.
- All routes require a valid Bearer token.

## API Strategy
- **Format**: RESTful API.
- **Contract**: OpenAPI (Swagger) generated by FastAPI.
- **Client**: Type-safe client generated from OpenAPI spec.
- **Isolation**: Every endpoint MUST follow the pattern `/api/{user_id}/tasks` or verify `task.user_id == authenticated_user_id`.

## Database Schema Strategy
- **SQLModel**: Unifies Pydantic schemas and SQLAlchemy models.
- **User Table**: Core user identity.
- **Todo Table**: Linked via `user_id` (foreign key).
- **Indexing**: Composite index on `(user_id, status)` for list performance.

## Non-Functional Requirements
- **Latency**: < 500ms p95.
- **Security**: Zero data leakage between users.
- **Portability**: Container-ready for Phase IV.
